# MusTag

用于个人验证的 iOS 18+ 音频元数据编辑器。SwiftUI 原生界面，支持中文/英文、浅色/深色。

## 打开和运行

1. 使用 Xcode 打开 `MusTag.xcodeproj`，选择 `MusTag` Scheme。
2. 选择已安装的 iPhone 或 iPad 模拟器运行。真机运行时，在 Signing & Capabilities 中选择自己的开发团队，并按需修改 Bundle Identifier。
3. 工程已包含固定版本的第三方源码；正常构建不需要下载依赖，也不需要安装包管理器。

工程使用本机已有的 XcodeGen 生成。修改 `project.yml` 后，可以运行 `xcodegen generate` 更新工程；日常使用直接打开 `.xcodeproj` 即可。

## 使用

- **底部导航**：依次为“首页”“连接”“设置”。首页保留空资料库欢迎页和音乐列表；设置页提供识别服务、AcoustID Key、备份恢复和开源许可。切换 tab 保留页面和编辑草稿，AcoustID 未配置 Key 时会自动切换到设置首页；输入 Key 后点击“保存 Key”生效。
- **连接入口**：支持文件/文件夹导入、WiFi 传歌，以及 WebDAV、SMB、FTP、Subsonic、Navidrome、飞牛音乐。连接配置保存在本机，密码存入 Keychain；提供验证连接、目录/专辑浏览、多选文件/文件夹、递归下载、进度、取消与失败重试。不接入网盘源，不提供任何远端上传、覆盖、重命名、删除或标签修改接口。
- **首次进入**：空资料库显示原创唱片与音乐标签插画，支持中文/英文、浅色/深色和动态字体。点击“导入音乐”选择文件或文件夹；“常见问题”说明支持格式、识别流程、预览保存和备份恢复。
- **本机文件**：所有导入和下载的 MP3、FLAC、M4A 都先保存为本地副本，位于系统“文件”→“我的 iPhone/iPad”→ MusTag → Music。编辑、保存与撤销只作用于此目录；原来源文件保持不变。可直接用“文件”App 查看、分享、复制或删除音频；在“连接”→“本机音乐文件夹”刷新列表。
- **文件夹分类**：首页按“文件夹”和“文件”展示导入内容。点击文件夹查看其中的音频（包含子目录），在文件夹内选择、识别和预览修改仅作用于该文件夹；首页的批量操作仍覆盖整个资料库。空文件夹也会保留入口，重复导入复用已有本地副本并保留草稿和分组，不用来源的新版本覆盖本地编辑。同名的不同文件夹会显示来源路径以便区分。
- 旧版本没有记录导入来源，原有条目会保留在“文件”分类；重新选择对应文件夹后即可归入文件夹，已有草稿会保留。
- **批量移除**：点击“选择”，勾选文件或“全选”，再点击底部“从列表移除”并确认。仅移除所选文件的列表记录和未保存的修改，原始音频和已保存的备份会保留；空文件夹入口也会保留。
- **手动编辑**：点开文件修改歌名、艺术家、专辑、专辑艺术家、日期、曲序、碟号或流派。
- **缺失项提示**：每首歌下方以柔和的标签列出待补充的封面及文字字段，随当前草稿更新，空间不足时自动换行。空白文字也视为缺失；补全后对应标签消失，未保存的修改仍显示待确认提示。检查覆盖应用支持的八项文字标签；歌词尚不在读取范围内。
- **识别服务**：默认使用 **ShazamKit**，无需填写 API Key；设置中可切换为 AcoustID，选择会保存在设备上。两种方式都支持所选文件、当前文件夹和全部资料库，不会在服务失败时自动切换到另一家。
- **Shazam 自动匹配**：直接读取文件生成音频签名，不使用麦克风。唯一匹配将歌名、艺术家、流派及可用封面填入草稿；多条歌曲匹配需手选，未匹配保留原草稿。不显示或伪造 AcoustID 相似度，不套用 90% 门槛。
- **Shazam 信息补全**：返回 Apple Music 歌曲标识时，通过 MusicKit 精确查询对应歌曲，补全可用的专辑、专辑艺术家、发行年份、曲序和碟号；Shazam 已返回的歌名、艺术家和流派优先保留。同一 Apple Music 歌曲只显示一个合并候选，不再把基础信息与补全信息分成两项。Apple Music 查询无结果、未获系统授权或服务不可用时，保留 Shazam 基础识别结果，不再查询其他元数据服务。缺失字段保留原值，候选中显示补全情况。
- **Shazam 专辑选择**：Apple Music 提供的是所匹配的数字发行版本，年份不一定是歌曲首次发行年份，曲序和碟号也不一定对应原文件的实体唱片。原专辑名称与 Apple Music 专辑不同时，自动匹配只填入歌曲信息，暂时保留草稿中的专辑信息和封面；同一候选内显示两边专辑，并提供“保留原专辑信息”和“采用 Apple Music 信息”。保留原专辑会恢复文件原有的专辑、专辑艺术家、年份、曲序、碟号及封面，可撤回之前采用的目录发行信息。不同歌曲或不同目录发行条目仍分别列为候选，所有修改均需预览后保存。
- **流派语言**：新识别的常见流派跟随 App 当前中英文语言，中文使用“流行”“国语流行”等名称，英文使用 Pop、Mandopop 等名称；预览与实际保存一致。同义名称去重，未知流派保留原文，原文件已有标签和手动编辑不会自动转换。切换语言后可重新识别生成对应语言的草稿。
- **AcoustID 自动匹配**：设置中填入自己的 **Application API Key** 后使用。候选按指纹相似度从高到低排列，自动采用最高分且达到 **90%** 的结果；门槛固定。未配置 Key 时仍可用 ShazamKit 和手动编辑。
- **AcoustID 返回内容**：使用 AcoustID 自身返回的歌名和艺术家，不再关联其他曲库查询专辑信息或封面。最高分并列、低于 90% 或未匹配的文件保留原草稿，提示手动处理；编辑页展示相似度和已采用标记，可手动改选（包括低于 90% 的候选）。相似度不代表识别正确率。
- **批量草稿**：自动匹配将文字标签和对应正面封面填入草稿，非空字段更新现有内容，空缺字段保留原值。每完成一个文件便保存草稿，单个文件失败后继续处理其他文件；结束时汇总已填入、待确认、未匹配及失败数量。点击“停止”保留已完成的草稿，正在处理和未处理的文件保持此前草稿。
- **封面**：列表和编辑页显示文件内嵌封面；点击封面可放大预览。下载失败或版本无封面时保留原封面，重新选择版本可重试；也可以单独撤销封面修改。
- **保存**：打开修改预览，核对文字差异和新旧封面对比，确认后保存到本机 Music 文件夹的音频副本。仅更换封面也可以保存。每次写入前备份原标签、所有封面和恢复所需的容器元数据，不保存音频内容。
- **撤销**：设置 → 撤销已保存的修改。结合现有音频文件与元数据备份，恢复修改前的文件；本地文件被其他 App 修改时拒绝自动覆盖。旧版完整文件备份仍支持恢复和导出，不会自动转换。

AcoustID Key 在 https://acoustid.org/new-application 注册应用后获取。不要使用提交指纹的 User API Key。密钥保存在设备 Keychain，不写进源码、URL 或普通配置文件。

## 连接与传输

- WebDAV 使用原生 URLSession；SMB 使用从 NetMusic 原样复用的本地 SMBClient 包（SMB 2.0.2/2.1）；FTP 使用原生 Network.framework 被动模式，支持 EPSV/PASV 和 MLSD/LIST，仅支持明文 ftp://。
- Subsonic/Navidrome 使用原始文件下载接口；飞牛参考 NetMusic 的原始媒体请求，不传转码参数。按服务器元数据核对文件大小，未知格式、CUE 分轨或已删除条目会显示不可用原因。
- HTTP/FTP 必须在连接设置中明确允许未加密连接。HTTP 请求拒绝重定向，地址需填写最终服务器地址；不会把密码或会话令牌发送给重定向目标。
- WiFi 传歌需电脑与设备连接同一局域网。在页面开启服务后，用电脑浏览器打开完整地址（含本次会话访问码），支持多文件及文件夹上传。同名文件保留两份，不覆盖已有编辑；退出页面或进入后台会停止服务。
- 下载按所选文件/文件夹进行，不自动拉取整个服务器。完整下载与音频校验通过后才放入 Music；重复选择已下载文件会复用本地副本，失败文件可重新选择重试。不会自动覆盖。
- Music 是正式资料而非缓存。移除连接、移除列表记录不会删除音频。卸载 App 会删除本机数据，请先通过“文件”保存需要保留的音乐。旧版本外部文件记录会在加载时尝试迁移；无法读取的来源需重新选择导入，保存/恢复均不会绕过本地目录限制。

## 文件安全

写入路径：连接下载/导入为永久本地副本 → 协调读取本地文件 → 本地暂存 → 检查本地文件哈希 → 备份标签、封面及容器元数据 → 只修改标签 → 重新读取标签 → 校验编码音频数据哈希 → 保存恢复记录 → 协调替换 → 再次校验。

- MP3 校验首个至最后一个 MPEG 帧；FLAC 校验元数据块之后的音频；M4A 校验 `mdat` 内容。修改标签不重新编码音频。
- 未编辑的属性、多值字段和封面交由 TagLib 保留；无法安全保留的旧 ID3 帧或声明“标签修改时丢弃”的帧会阻止写入。
- MP3/FLAC 更换正面封面时保留背面等其他图片；M4A 更换第一张封面并保留后续图片。写后重新读取并校验封面和音频数据；撤销时将备份的元数据与现有音频内容重新组合，并校验恢复后的完整文件哈希。
- 新备份以 `.mustagbackup` 元数据包保存在本机 Application Support，大小主要取决于标签、内嵌封面及容器元数据，不再额外保留整份音频数据；同一文件每次保存仍新增一份备份。安全写入和恢复仍需临时音频副本，操作结束后清理。
- “导出备份”可留存元数据包；元数据包不是可播放音频，也不能单独恢复丢失的音频文件。旧版完整文件备份仍导出原音频文件。卸载 App 会删除本机备份；撤销需要保留对应音频文件及 App 数据。
- 本机文件无法安全替换时，操作会失败并保留备份。保存成功表示 Music 中的本地副本已更新，应用没有远端回写或同步功能。
- 全库处理使用逐文件暂存。iOS 后台可能暂停下载或识别；被系统终止的未完成任务需重试，完整下载的文件、已保存草稿和备份会保留。

## 识别服务

ShazamKit 和 MusicKit 均使用系统框架，不新增第三方依赖。AVFoundation 分块解码开头最多三个片段，每段通常最多 12 秒，并遵守 Shazam 曲库的查询时长限制；识别阶段只向 Apple 发送不可逆音频签名。未命中时尝试下一段，命中后停止；每次匹配最多等待 30 秒，可以取消。不使用麦克风，也不播放歌曲或写入 Shazam 历史。

首次真实识别前，需要在 [Apple Developer → Certificates, Identifiers & Profiles](https://developer.apple.com/help/account/services/shazamkit/) 中为实际使用的 App ID 启用 **App Services → ShazamKit**，并用对应开发团队签名。工程已链接系统 ShazamKit.framework，但代码和模拟测试无法替代账户侧服务启用。项目保留现有 Bundle Identifier/签名团队；若使用自己的团队，请同步修改 App ID 和签名配置。

Apple Music 补全还需要在同一 App ID 的 **App Services → MusicKit** 中启用服务，使 MusicKit 能自动生成开发者令牌。工程已链接 MusicKit.framework，并在 Info.plist 配置 `NSAppleMusicUsageDescription`。首次需要查询 Apple Music 时，系统会请求音乐访问授权；拒绝后仍可使用 Shazam 基础识别和手动编辑，可在系统设置中重新授权。此流程只查询目录元数据，不读取个人曲库、修改播放列表或发起播放。

Apple Music 通过 Shazam 返回的歌曲标识查询对应目录条目。封面仅接受返回的 HTTPS `mzstatic.com` 及其子域链接；缺失、格式不支持、超限或下载失败时保留原封面。候选和已采用内容显示 Apple Music 链接（返回链接时）；最近采用的 Shazam 识别记录随草稿、保存和备份恢复持久化，重启后仍可查看。后续手工编辑或选择其他匹配可能只保留部分 Shazam 字段，因此这条记录不表示当前全部标签均来自 Shazam。

选择 AcoustID 时，端侧使用 AVFoundation 解码、Chromaprint 计算真实指纹，向 AcoustID 仅上传指纹与时长，读取响应中的基础歌名和艺术家。已移除 MusicBrainz 自动补全、按歌名搜索及 AcoustID 关联查询。

Shazam / Apple Music 候选使用对应元数据返回的 Apple 图片地址，不再查询 Cover Art Archive 或 Internet Archive；不向封面地址发送音频、指纹或 AcoustID Key。支持 JPEG/PNG，单张最多 8 MiB、4000 万像素。未确认保存的封面随草稿保留，下载或取消操作不会改动原文件。

这是个人验证配置。AcoustID 请求限制为至少 0.35 秒间隔。当前自动化测试使用固定匹配响应，不代表 ShazamKit 或 AcoustID 的真实在线命中率；新增 Apple Music 补全的真实目录响应及系统授权流程仍需在启用 MusicKit 的签名设备上验证。

## 测试

运行 Xcode 的 Product → Test；或者使用本机已安装的模拟器：

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
xcodebuild -project MusTag.xcodeproj -scheme MusTag \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro,OS=18.6' \
  -derivedDataPath work/DerivedData -parallel-testing-enabled NO \
  -disableAutomaticPackageResolution -skipPackageUpdates test
```

如果本机存在重名模拟器，请使用 `id=设备 UUID` 替代名称。测试不自动下载运行时或依赖。
